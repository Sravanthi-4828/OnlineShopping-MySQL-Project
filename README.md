# 🛒 Online Shopping Database – MySQL Project

## 📌 Project Overview

This project focuses on designing and querying an Online Shopping Database using **MySQL**. It demonstrates my understanding of SQL concepts, database management, and data analysis through practical queries.

The project covers SQL fundamentals as well as advanced concepts, including joins, subqueries, aggregate functions, conditional statements, and window functions.

The objective is to build a strong foundation in SQL and apply database querying techniques to solve business-related problems and extract meaningful insights.

## 🛠️ Technologies Used

- MySQL
- SQL
- MySQL Workbench

## 📚 Topics Covered

- DDL – Data Definition Language
- DML – Data Manipulation Language
- DQL – Data Query Language
- SQL Operators
- Aggregate and Built-in Functions
- GROUP BY and HAVING
- Joins
- Subqueries
- IF and CASE Statements
- Window Functions
- Business Analysis Queries

## 📂 Project Structure

| File | Description |
|---|---|
| `level01_ddl.sql` | Database and table creation |
| `level02_dml.sql` | Data insertion and manipulation |
| `level03_dql_basic.sql` | Basic SELECT queries |
| `level04_operators.sql` | SQL operators |
| `level05_functions.sql` | SQL functions |
| `level06_group_having.sql` | Grouping and filtering |
| `level07_joins.sql` | Different types of joins |
| `level08_subqueries.sql` | Nested queries |
| `level09_if_case.sql` | Conditional statements |
| `level10_window_functions.sql` | Window functions |
| `final_business_analysis.sql` | Business analysis queries |

## 🎯 Key Learning Outcomes

- Understanding relational database concepts.
- Writing SQL queries to retrieve and manipulate data.
- Combining data from multiple tables using joins.
- Performing aggregations and analytical calculations.
- Using subqueries and window functions.
- Applying SQL concepts to business-oriented problems.

## ▶️ How to Run the Project

1. Install MySQL and open MySQL Workbench.
2. Clone or download this repository.
3. Open the SQL files in MySQL Workbench.
4. Execute the scripts in the appropriate order, starting with DDL.
5. Run the business analysis queries to explore the database.
